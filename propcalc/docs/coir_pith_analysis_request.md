# 코코피트(coir pith) 분석 의뢰서

목적: propcalc에 코코피트를 연료로 입력하기 위한 입력값 확보. 작업 지시서의 원칙은 "같은 시료의 원소분석과 실측 HHV"이며, 문헌값을 섞으면 ΔfH° 오차가 수백 kJ/mol에 이를 수 있습니다. 이 의뢰서는 그 기준을 충족하도록 항목과 보고 형식을 고정합니다.

## 1. 시료 정보 (의뢰서에 반드시 기록)

| 항목 | 기록 내용 |
|---|---|
| 공급처, 로트 번호 | 같은 로트에서 모든 분석 시료를 채취 |
| 제품 형태 | 압축 블록 / 느슨한 분말 등 |
| 처리 이력 | 세척, 완충(buffering), 염 처리 여부. 원예용 코코피트는 EC를 낮추려고 세척하거나 칼슘 등으로 완충하는 경우가 있어 회분과 무기염 조성이 달라질 수 있습니다(일반적으로 알려진 내용이며 이 세션에서 출처를 확인하지 못했습니다). 처리 이력을 모르면 모른다고 기록하세요 |
| 전처리 | 분쇄·체질 입도, 건조 조건(예: 105℃ 항량) |
| 보관 | 분석 전까지 밀폐 보관 (흡습성이 강함) |

## 2. 의뢰 항목

핵심 항목은 모두 같은 균질화 시료의 한 배치에서 측정해야 합니다.

| 항목 | 요청 사항 | 참고 방법(기관 보유 방법을 우선, 번호는 확인 필요) |
|---|---|---|
| 수분 | 받은 상태 기준 | ISO 18134 계열 |
| 회분 | 건조 기준 | ISO 18122 |
| C, H, N | 건조 기준, 질량% | ISO 16948 |
| S | 건조 기준, 질량% | ISO 16994 |
| O | 직접 측정이 가능하면 직접 측정, 아니면 차이법이라고 명시 | 기관별 상이 |
| HHV | 건조 시료, 봄브 열량계, MJ/kg(정적 연소열임을 명시), 벤조산 교정 기록 | ISO 18125 |
| 선택: 휘발분 | 건조 기준 | ISO 18123 |
| 선택: 리그닌, 셀룰로오스, 헤미셀룰로오스 | 섬유분석 | 기관별 상이 |
| 선택: 회분의 원소 조성 | K, Ca, Mg, Na, Si, P 등 (ICP 계열) | 기관별 상이 |

표준 번호는 제가 알고 있는 것을 적은 것으로, 이 세션에서 원문을 확인하지 못했습니다. 기관과 확인하세요.

## 3. 보고서에 요구할 사항

1. 모든 값에 기준(건조/받은 상태)을 명시. 원소분석과 HHV는 같은 기준(건조)으로 받습니다.
2. 반복 측정 3회 이상의 평균과 표준편차. HHV의 표준편차는 민감도 분석의 입력이 됩니다.
3. O를 차이법으로 구했는지 직접 측정했는지. 차이법이면 다른 원소의 오차가 모두 O에 쌓입니다.
4. C+H+N+S+O+회분의 합(건조 기준)이 100±1.5% 안인지. 벗어나면 분석 누락이나 기준 혼용입니다.
5. 열량계 교정 정보와 시료량.

## 4. 결과 접수 (propcalc)

```python
from propcalc.hess import dHf_from_dry_basis_report
from propcalc.mixture import Ingredient

r = dHf_from_dry_basis_report(
    C=..., H=..., N=..., S=..., ash=..., hhv_dry_MJ_per_kg=...,   # 모두 건조 기준
    O=None,                                  # 직접 측정값이 있으면 입력, 없으면 차이법
    u_hhv_dry_MJ_per_kg=...,                 # 반복 측정의 표준편차
)
print(r.dHf_kJ_per_mol, r.u_dHf_kJ_per_mol, r.warnings)
```

함수는 건조 기준 값을 건조·무회분 기준으로 환산하고, 합이 어긋나면 거부하며, 산소 차이법과 회분 제외를 결과의 `warnings`에 남깁니다. 결과를 DB에 넣을 때는 `source`에 보고서 번호, 시험 기관, 시험일을 적고, 보고서 원본을 직접 확인했으므로 `verification: primary`로 지정합니다.

## 5. 해석할 때의 한계

1. 회분은 반응물에서 제외됩니다. 코코피트는 회분 비중이 클 수 있어, 회분 질량만큼 배합 질량이 어긋나고 회분의 K, Ca 등이 평형 생성물에 미치는 영향은 반영되지 않습니다. 회분 원소 조성(선택 항목)을 받아 두면 이후 확장할 수 있습니다.
2. 연료 HHV의 영향이 큽니다. 셀룰로오스 민감도(ΔfH° ±30 kJ/mol, HHV 환산 ±0.185 MJ/kg에서 Tc ±28 K)를 선형 외삽하면 HHV 1 MJ/kg당 Tc가 약 150 K 바뀝니다. 외삽이고 상전이 plateau 때문에 비선형이므로 대략적인 규모로만 보세요. 그래서 HHV는 반드시 실측하고 반복 측정의 표준편차를 받아야 합니다.
3. HHV를 ΔcH°로 취급하는 단순화(정적 연소열과의 차이)는 그대로 유지됩니다.
