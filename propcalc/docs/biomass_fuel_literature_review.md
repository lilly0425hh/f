# 커피박·귤껍질 문헌 원문 확인 기록 (2026-10-31)

기준은 [coir_pith_literature_intake.md](coir_pith_literature_intake.md)의 5개 조건(대상 시료, 같은 표의 C·H·N·S·O, 같은 시료의 회분·수분·실측 HHV, 기준 명시, HHV가 계산값이 아님)과 등급(A~D)입니다. 방법은 PMC(eutils)에서 시료 용어와 발열량·원소분석 용어로 검색해 본문 표를 직접 확인한 것입니다. PMC 공개 본문만 봤고, 유료 논문과 이미지 표는 확인하지 못했습니다.

## 커피박 (spent coffee grounds)

| 논문 | 등급 | 내용 |
|---|---|---|
| Mukherjee 외, ACS Omega 2021, PMC8756566 | A(조건부) | Table 1과 Table 4의 같은 시료 "raw material" 행. C 50, H 6.7, N 2.3, S 0.9, O 39.0(차이법), 회분 0.9, 수분 3.3 %, HHV 22.3 MJ/kg(dry basis, PARR 6400 열량계). 방법 절에 "dried basis"가 명시됨 |
| PMC9911335, J Therm Anal Calorim 2023 | B | 순수 SCG 표(C 48.69, H 6.89, N 2.31, S 0.08, O 42.03, 회분 1.66, 수분 9.29, HHV 20.71)가 있으나 HHV를 Channiwala–Parikh 상관식으로 계산함 |
| PMC6862488, Materials 2019 | B | 건조 SCG의 C 48.67, H 6.54, N 2.27, O 40.03, 회분 2.43, HHV 20.48이지만 HHV를 식 (1)로 계산함 |
| PMC7933292, Sci Rep 2021 | B | C 68.52±10.20 %, H 11.04±3.05 %로 바이오매스로는 비현실적이고 O가 없으며 수분 42.31 %라 기준이 불분명. 제외 |
| PMC9061234, Environ Dev Sustain 2022 | 비교표(2차) | 다른 문헌 값을 모은 표. SCG 16개 값이 19.30~24.91 MJ/kg(평균 22.06, SD 1.80). 같은 시료 세트가 아니므로 입력으로 쓰지 않고 산포의 근거로만 사용 |

PMC8756566을 A(조건부)로 둔 이유와 한계는 다음과 같습니다.

1. 반복 측정 SD가 없습니다. 그래서 `SPENT_COFFEE_GROUNDS`의 불확실도는 측정 불확실도가 아니라 위 16개 값의 문헌 간 SD(1.80 MJ/kg)로 정했고, 이는 ΔfH° ±436 kJ/mol에 해당합니다. 이 값은 논문 간 시료·처리 차이를 섞은 것이라 "커피박 일반"의 범위 보증이 아닙니다.
2. 시료를 증류수로 세척하고 105 도에서 건조한 전처리를 했습니다(회분과 추출물이 달라질 수 있음).
3. C가 정수(50)로 보고되어 반올림 오차가 큽니다. 합이 99.8 %입니다.
4. "dried basis" 표에 수분 3.3 %가 같이 있어 기준이 완전히 일관되지 않습니다. 수분 포함 기준으로 읽으면 ΔfH°가 −891.2에서 −765.8 kJ/mol로 바뀝니다.
5. HHV 측정 표준 번호와 반복 횟수가 없습니다.

## 귤껍질

감귤·귤·오렌지 껍질 자체의 같은 시료 세트는 PMC에서 찾지 못했습니다(80편 확인, 대상은 대부분 다른 재료). 유일하게 나온 감귤류는 레몬 껍질입니다.

| 논문 | 등급 | 내용 |
|---|---|---|
| Ismail 외, Polymers 2025;17(21):2830, doi 10.3390/polym17212830, PMC12610777 (레몬 껍질) | B | C 54.09±0.16, H 4.95±0.03, N 1.26±0.03, S 0.20±0.04, O 34.20±0.18(차이법), 회분 5.30±0.03, 수분 9.73±0.02, HHV 23.02±0.05 MJ/kg(Parr 1341EE 봄브 열량계, 벤조산 교정, 3회 반복) |

레몬 껍질은 귤껍질이 아니고, 기준에 문제가 있습니다. 원소분석 표는 "dry basis"라 하면서 O를 `100 − (C+H+N+S+회분)`으로 구하는데, 그 회분 5.30은 수분 9.73 %를 포함한 근사분석(TGA 기반, 합 99.93 %)에서 온 값입니다. HHV의 기준은 적혀 있지 않습니다. 이 값을 DB에 넣으려면 기준 가정이 필요하고 레몬을 귤의 대용으로 쓰는 가정도 필요하므로, 입력하지 않았습니다.

## 귤껍질을 찾으려면

DBpia, KCI, RISS에서 아래 검색어로 감귤 부산물의 연료 특성 논문을 찾으세요. 제주 감귤 부산물은 국내 고형연료·열분해 연구가 있을 수 있습니다(존재는 확인하지 못했습니다).

- 한국어: 감귤 부산물, 감귤박, 감귤 과피, 귤껍질, 감귤 착즙박 + 고형연료, 열분해, 가스화, 원소분석, 발열량, 공업분석
- 영어: mandarin peel, tangerine peel, Citrus unshiu peel, satsuma peel, citrus peel waste + "ultimate analysis", HHV, bomb calorimeter, pyrolysis, torrefaction

채택 조건은 같습니다. 같은 표의 C·H·N·S·O, 같은 시료의 회분·수분·봄브 열량계 HHV, 기준 명시, HHV가 계산값이 아닐 것.
